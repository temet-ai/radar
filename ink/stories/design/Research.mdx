# Research and readiness

Board 09 of the design canvas, as text. Checked on 13 October 2026, in four parts: radar's own renderer code (ink/src and crates/radar-core), the terminals' own docs and issue trackers, the Ink 8 ecosystem on npm, and how lazygit, k9s, Textual, Charm's tools, yazi and others solve the same problems. Every proposal on sheets 00–08 is listed with its verdict. Where a source could not be fetched it says so.

Every proposal here is a **target, not built yet** unless its verdict says shipped. The issue column names the issue that builds it (issue #47 orders them).

## Decisions for you

- Decided · no chevrons Chevrons are banned for expand and collapse, as GUIDE 2.12 says. Folding shows as tree lines and a trailing ⋯ n, in every part. Breadcrumbs join with / instead of ›. Both are now applied on every sheet.
- The emoji pack Terminals, tmux and string-width libraries disagree about emoji width (VS16 and joined emoji worst), so an emoji in a fixed two-cell slot can still push a row out of line. Keep the emoji pack with a width measured from the terminal at start, or drop it?
- Sized text and letterforms kitty's sized text only draws in kitty, and Unicode maths letters fall back to other fonts. The guide now marks both as parked. Leave them parked, or keep sized text as a kitty-only extra behind a probe?

## Order

- 1 · Cheap wins Scrim and shadow behind overlays, tinted chips, the gradient focus border and wordmark, fold unroll and the rainbow lap, the tab attention dot. Ink plus the matching change to the earlier renderer. Ink 8's built-in scrolling and shared animation timer come along here.
- 2 · Graph, palette, editor The pipeline graph (dagre, a new graph node from the host), the cross-part command palette (host target list, Ink draws the typed menu it already has), and the editor preview (host sends rendered markdown blocks; shiki colours the code).
- 3 · Then Port Slack images to Ink, then avatars. Charts from host series data (ink-chart's LineGraph). Mermaid last, after the licence and parity calls. Notices with a lifetime and history, the assemble motion, the icon slot and underlined keys in hints as host changes allow.

## Adopted from other terminal apps

- **Detail panes** (gh-dash, k9s describe · sheet 08): A fixed skeleton: a head, a facts grid with dim labels padded to the longest, then sections. Empty fields are left out, not shown as “none”.
- **Loading** (yazi, Charm bubbles · sheets 06, 07): Cached rows show at once and are marked stale; the spinner goes in the pane title, not the content. Outline rows only when there is nothing yet. A pane that has data is never blanked.
- **Notices** (Textual notify · sheets 06, 07): Information stays about 5 s, errors about 10 s or until a key. Past notices are kept in a history behind one key.
- **Command palette** (Textual, Posting, fzf · sheet 06): An empty input shows a short discovery list, with the current item’s actions first. Matched letters lit, each command’s key on the right, a count like 3 of 128.
- **Focus** (lazygit · sheets 06, 08): Three signals together: border colour, bold title, and the selection dimmed in unfocused panes. A jump number before each pane title.
- **Trees** (lazygit, lipgloss · sheet 05): = opens every node. Folded rows show how many they hide (⋯ n). Guide lines dim. No chevrons.
- **Pipelines** (glab ci view, Dagger · sheet 05): Stage columns with a glyph per job; on a narrow screen fall back to the stage list with only failed or running jobs open.
- **Theme slots** (Textual, k9s, lipgloss · sheet 01): A few base colours with derived shades and muted blends, slots named by role, and a 16-colour value for each: radar’s slots already work this way.
- **What reads as noise** (survey · all sheets): Gradients everywhere, several spinners at once, shimmer on static text, toasts over the work, colour as the only signal, joke animations on by default.
