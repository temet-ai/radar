Icons wherever they
say something.

An icon is a word you read before the word. radar names icons, never glyphs: a part asks for run_failed and the pack decides how it looks. Packs swap whole (nerd, unicode, emoji, off, or your own), any single icon can be overridden in [icons], and each icon carries its default colour slot.

Packs

The same row in each built-in pack. auto picks nerd in Ghostty, kitty and WezTerm, unicode over SSH.

Changing pack must never move the screen. Today emoji are two cells and off is none, so every column after an icon jumps.

Every icon gets the same two cells, whatever the pack: a one-cell glyph and its gap, an emoji filling both, or blank when icons are off. Columns are laid out from the slot, never from the glyph, so the screen you know stays put when you change pack. The shaded bands are the slots.

Part marks

Tabs carry whatever icon the part sends; today there is no agreed mark per service. These make each part recognisable in the tab bar and in a cross-part list.

Several to a row

Column heads, chips, people, states, tabs, menus and settings rows all take icons. A row can hold four if each one says a different thing.

Colour comes with it

An icon draws in its own slot, then the words follow in the tone's. A passed check is green before it is read.

Never the only signal

The off pack must still read. Every icon sits beside a word, a count or a column that says the same thing.
