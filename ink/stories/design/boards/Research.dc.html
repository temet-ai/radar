Decisions for you

Decided · no chevrons

Chevrons are banned for expand and collapse, as GUIDE 2.12 says. Folding shows as tree lines and a trailing ⋯ n, in every part. Breadcrumbs join with / instead of ›. Both are now applied on every sheet.

The emoji pack

Terminals, tmux and string-width libraries disagree about emoji width (VS16 and joined emoji worst), so an emoji in a fixed two-cell slot can still push a row out of line. Keep the emoji pack with a width measured from the terminal at start, or drop it?

Sized text and letterforms

kitty's sized text only draws in kitty, and Unicode maths letters fall back to other fonts. The guide now marks both as parked. Leave them parked, or keep sized text as a kitty-only extra behind a probe?

Parity

The Rust renderer can't run these JavaScript libraries. Side by side it would show source text where Ink draws a graph, code colours or a diagram. Each needs a matching Rust drawing (syntect for code colours; a graph layout written or found in Rust, not yet researched), or an agreed Ink-only exception.

Theme

shiki takes a theme built from radar's slots. A small syntax.* slot set (keyword, string, number, comment, type, function) in the host's look would let users recolour code like everything else. On no colour, skip shiki and draw text.primary.

Order

1 · Cheap wins

Scrim and shadow behind overlays, tinted chips, the gradient focus border and wordmark, fold unroll and the rainbow lap, the tab attention dot. Ink plus the matching change to the earlier renderer. Ink 8's built-in scrolling and shared animation timer come along here.

2 · Graph, palette, editor

The pipeline graph (dagre, a new graph node from the host), the cross-part command palette (host target list, Ink draws the typed menu it already has), and the editor preview (host sends rendered markdown blocks; shiki colours the code).

3 · Then

Port Slack images to Ink, then avatars. Charts from host series data (ink-chart's LineGraph). Mermaid last, after the licence and parity calls. Notices with a lifetime and history, the assemble motion, the icon slot and underlined keys in hints as host changes allow.
